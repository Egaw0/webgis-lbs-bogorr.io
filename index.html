    Peta dasar tidak bisa dimuat

    Data peta dasar tidak sampai ke perangkat ini. Penyebab yang paling umum:

    1. File dibuka di pratinjau (misalnya pratinjau di aplikasi chat atau email) yang memblokir gambar dari internet. Unduh filenya, lalu buka dengan Chrome, Edge, atau Firefox.
    2. Tidak ada koneksi internet, atau jaringan kantor memblokir server peta. Coba jaringan lain, misalnya hotspot HP.

    API key Google Maps

    Opsional. Tanpa key, peta Google memakai alamat ubin tidak resmi yang bisa diblokir Google sewaktu-waktu. Dengan key, aplikasi memakai Map Tiles API resmi dari Google Maps Platform: 100.000 ubin peta per bulan gratis, di atas itu ditagih Google.

    1. Buka console.cloud.google.com, buat atau pilih project.
    2. Aktifkan penagihan (billing) pada project. Ini wajib walau pemakaian masih di bawah kuota gratis.
    3. Di APIs & Services → Library, aktifkan Map Tiles API.
    4. Di Credentials → Create credentials → API key, salin key-nya. Batasi key hanya untuk Map Tiles API. Kalau halaman ini dibuka dari file di komputer, jangan pakai pembatasan HTTP referrer, karena file lokal tidak mengirim alamat situs.

    Key hanya disimpan di browser ini, tidak ikut di dalam file.
